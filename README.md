# analisi-multilingue
# 🌍 Multilingual Text Analyzer (NLP Basics)

A simple Python script built to explore basic **Computational Linguistics** and **Natural Language Processing (NLP)** concepts across multiple languages and writing systems.

## ✨ Features
- **Word Count & Length Analysis:** Cleans basic punctuation and calculates the total word count and average word length for each input sentence.
- **Script Detection:** Automatically detects the presence of **Cyrillic characters** (used in Russian) alongside Latin-script languages (English and Spanish).

## 🛠️ Technologies Used
- **Python 3** (Strings, Dictionaries, List Comprehensions, Unicode character range checking)
- **Google Colab** for testing and execution

## 🚀 Languages Analyzed
- 🇬🇧 English
- 🇪🇸 Spanish
- 🇷🇺 Russian

## 📌 Future Improvements
- Add support for non-spaced and non-Latin writing systems such as **Mandarin Chinese** or **Arabic**.
- Integrate basic sentiment analysis or tokenization libraries (e.g., `NLTK` or `spaCy`).
